## 补充说明

| 项目 | 说明 |
|------|------|
| **图片格式** | 建议使用 `.png` 格式，支持透明背景，推荐尺寸 256×256 或 512×512 |
| **命名规则** | 必须与上方列表**完全一致**（区分大小写） |
| **缺失后果** | 页面自动显示首字母占位块，功能不受影响 |
| **图标来源** | 可使用 [Flaticon](https://www.flaticon.com/)、[The Noun Project](https://thenounproject.com/)、[FontAwesome](https://fontawesome.com/) 等网站获取图标 |
| **特殊说明** | `materialism_lifestyle.png` 和 `naturalism_art.png` 用于区分同名但不同领域的主义 |
